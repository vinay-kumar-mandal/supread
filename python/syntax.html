Python Basic Syntax

Python ki syntax bahut hi clean aur padhne mein aasan hoti hai. Yeh doosri programming languages ke mukable brackets {} ki jagah indentation (spaces) par nirbhar karti hai.

The Print Statement

Screen par kuch bhi output dikhane ke liye hum print() function ka use karte hain.

example.py 
print("Hello, World!")
print("Welcome to Supread Docs")

Indentation

Python mein code block define karne ke liye spaces ka use hota hai. Agar aap sahi se indent nahi karenge, toh error aayega.
